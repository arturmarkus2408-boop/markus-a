# MARKUS-A — обновление до версии 3

## 1. Файлы приложения → GitHub (5 минут)
1. На компьютере распакуйте архив `markus-a-v3.zip` (правой кнопкой → «Извлечь всё»).
2. Откройте github.com → репозиторий **markus-a** → **Add file → Upload files**.
3. Откройте распакованную папку и перетащите в окно браузера **всё, кроме папки `supabase`**:
   папки `js`, `css`, `icons` и файлы `index.html`, `sw.js`, `manifest.json`, `config.js`.
   В папке `js` три новых файла: `places.js`, `help.js`, `assist.js` — они тоже должны загрузиться.
4. Внизу нажмите зелёную кнопку **Commit changes**.

## 2. База данных (1 минута, можно повторять)
Supabase → **SQL Editor** → вставьте текст файла `supabase/migration-v2.sql` → **Run**.
(Если вы уже запускали его в прошлый раз — ничего страшного, запуск повторно безопасен.)

## 3. Telegram-бот и напоминания (5 минут)
1. Supabase → **Edge Functions → telegram-bot → Code** → выделить всё (Ctrl+A) → удалить →
   вставить весь текст из `supabase/functions/telegram-bot/index.ts` → **Deploy**.
2. То же для функции **reminders** (файл `supabase/functions/reminders/index.ts`).
3. У обеих функций во вкладке **Settings** переключатель **Verify JWT** — **выключен** → Save changes.

## 4. Телефон
1. Откройте MARKUS-A, полностью закройте и откройте снова (подтянется версия 3.0 — видно внизу Настроек).
2. Разрешите микрофон навсегда: в Chrome откройте сайт приложения → значок слева от адреса →
   «Разрешения» → Микрофон → **Разрешить**. Без этого автозапись будет спрашивать разрешение.

## 5. Как проверить автозапись
1. Создайте встречу, которая начнётся через 5 минут (автозапись уже включена по умолчанию).
2. Оставьте MARKUS-A открытым на экране (на главном экране будет кнопка «чтобы экран не гас»).
3. За 2 минуты до начала телефон коротко вибрирует и в правом верхнем углу появится маленькая серая точка — запись идёт.
4. Нажмите на точку — «Остановить и сохранить». Через 1–3 минуты придут итоги и задачи.
