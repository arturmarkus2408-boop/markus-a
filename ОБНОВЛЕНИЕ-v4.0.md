# MARKUS-A 4.0

## Ваши пункты
1. **Голосовой ответ в «Чате с AI».** Нажмите 🎤 и задайте вопрос: он отправится сам, как только вы замолчите, и ответ прозвучит **голосом**. По умолчанию — мужской голос Gemini «Charon» (как в приложении Gemini).
   * Сверху появляется плеер: **⏸ пауза / ▶ продолжить / ■ стоп**. Он виден на любом экране.
   * У каждого ответа есть кнопка «Прослушать / Стоп».
   * Голос выбирается в Настройках → «Голос ответов»: 3 мужских, 2 женских или голос телефона. Там же кнопка «Послушать».
   * Голос Gemini работает через ваш бесплатный ключ и имеет дневной лимит. Если лимит закончится или пропадёт интернет, ответ дочитает голос телефона — приложение скажет об этом.
2. **У каждого вопроса-окна есть ✕.** Длинное название задачи больше не растягивает окно: оно показано коротко, а кнопки «Удалить / Отмена» всегда видны.
3. **Карточка задачи:** верхняя строка (✎ PDF 🗑 ☆ ✕) теперь закреплена при прокрутке.

## Исправленные ошибки (проверка всего приложения)
* Очень длинный текст (ответ AI, пересланное сообщение, вставка в название) больше не становится названием. В название идёт первая фраза, **весь текст — в описание**, ничего не теряется.
* Удаление файла из открытого редактора: файл больше не «возвращается» после «Сохранить», а редактор не закрывается сам.
* Пока AI обрабатывает встречу, ваши правки во встрече больше не перезаписываются.
* Режим «Хранить только в облаке»: пометка «файл в облаке» восстанавливается сама, файлы больше не пропадают.
* «Отмена» при выполнении задачи с шагами оставляет шаги неотмеченными.
* Имена с апострофом (G‘ulom, O‘tkir) удаляются из участников нормально.
* «Изменить» в меню ⋮ у заметки открывает заметку, а не задачу.
* Встреча, открытая из карточки контакта, теперь сразу видна: окно закрывается.
* Смена ссылки на место сразу меняет точку на карте.
* Выход из аккаунта очищает устройство, чтобы данные двух аккаунтов не смешивались. Если что-то не отправлено в облако, приложение предупредит.
* Изменение времени напоминаний в Настройках больше не перезаписывает правки с другого устройства.
* Неправильная дата или время от AI больше не ломают календарь.
* Длинные уведомления обрезаются и не закрывают экран.
* Поля в два столбца не вылезают за край на маленьких телефонах.
* Запись встречи больше не скачивается заново при каждом обновлении экрана.
* При удалении заметки или контакта их файлы тоже освобождают память.

## Та самая длинная задача
Её теперь можно удалить: карточка → 🗑 → «Удалить». Если хотите сохранить, нажмите «Изменить» → «Сохранить»: название сократится, а весь текст уйдёт в описание.

## Установка

**На компьютере — сайт (обязательно):**
1. Распакуйте **markus-a-v4.0.zip**: правой кнопкой мыши → «Извлечь всё…» → «Извлечь».
2. Откройте github.com → репозиторий **markus-a** → **Add file** → **Upload files**.
3. Откройте распакованную папку `markus-a` и нажмите **Ctrl + A**. Затем зажмите **Ctrl** и щёлкните по папке `supabase`, чтобы снять с неё выделение.
4. Перетащите выделенное в окно GitHub → дождитесь загрузки → **Commit changes**.
5. Проверьте, что в папке `js` на GitHub появился файл **tts.js**.

**На компьютере — Telegram-бот (желательно, 3 минуты):** нужно, чтобы длинное пересланное боту сообщение тоже получало короткое название.
1. Откройте supabase.com → ваш проект → **Edge Functions** → **telegram-bot** → вкладка **Code**.
2. Щёлкните в код, нажмите **Ctrl + A**, затем **Delete**.
3. Откройте **telegram-bot-index.ts** Блокнотом, нажмите **Ctrl + A**, затем **Ctrl + C**.
4. Вернитесь в Supabase, щёлкните в пустое поле, нажмите **Ctrl + V** → **Deploy**. Первая строка должна быть `// MARKUS-A v3.6 — Telegram-бот`.

**На телефоне:**
1. Нажмите кнопку «Недавние» ▢ → смахните MARKUS-A вверх → откройте снова. Повторите это 2 раза.
2. Откройте «Ещё» → «Настройки». Внизу должно быть написано **«версия 4.0»**.
3. Проверка голоса: «Настройки» → «Голос ответов» → «Послушать».
