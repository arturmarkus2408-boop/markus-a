# MARKUS-A 3.2 — что нового

* Кнопки теперь заметно реагируют на нажатие. Во время отправки кнопка показывает «Отправляю…» и не нажимается повторно.
  Потом она становится зелёной «✓ Отправлено» или красной «✗ Не получилось», а причина видна на экране.
* Итоги в Telegram: под кнопкой написано, куда они придут (в чат с ботом @MarkusJW_bot, а не в «Избранное»),
  когда они доставлены и что случилось, если не дошли. Длинные итоги приходят несколькими сообщениями и не обрезаются.
* Качество записи: Экономное / Высокое (по умолчанию) / Максимальное.
  Режим микрофона: Обычный / Дальний и тихий звук / Шумное место.
  Есть «Тест микрофона»: он делает 3 записи по 15 секунд, вы их слушаете и выбираете лучший режим.
* При прослушивании записи есть кнопка «🔊 Усилить тихие звуки».
* Записи больше 40 МБ отправляются в облако частями (бесплатное облако не принимает файлы больше 50 МБ).

## Порядок обновления
1. ПК → GitHub → репозиторий **markus-a** → Add file → Upload files → всё из папки markus-a, кроме supabase → Commit changes.
2. ПК → Supabase → Edge Functions → **telegram-bot** → Code → Ctrl+A → Delete → вставить текст файла
   `supabase/functions/telegram-bot/index.ts` → **Deploy**.
3. ПК → GitHub → репозиторий **markus-a-android** → загрузить новые файлы → дождаться зелёной галочки в Actions →
   скачать новый MARKUS-A.apk в Releases → поставить на телефон поверх старого.
