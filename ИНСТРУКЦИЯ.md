# MARKUS-A — пошаговый запуск

Всё бесплатно. Время: ~40 минут один раз.

**Можно по частям.** После шагов 1–2 приложение уже полностью работает на одном устройстве: календарь, задачи, голос, запись и AI-анализ встреч, документы, заметки, поиск. Шаги 3–8 добавляют синхронизацию телефона и компьютера, Telegram-бота и ссылки «Поделиться».

---

## Шаг 1. Выложить приложение на GitHub

1. github.com → зелёная кнопка **New** → имя репозитория `markus-a` → **Public** → **Create repository**.
2. На странице репозитория нажмите **uploading an existing file**.
3. Распакуйте архив. Откройте папку `markus-a` и перетащите **всё её содержимое** (файлы и папки `css`, `js`, `icons`, `supabase`) в окно GitHub. Саму папку перетаскивать не нужно, только то, что внутри.
4. Внизу нажмите **Commit changes**.
5. **Settings** → слева **Pages** → Branch: `main`, папка `/ (root)` → **Save**.
6. Через 1–2 минуты приложение откроется по адресу:
   **https://arturmarkus2408-boop.github.io/markus-a/**

При первом открытии MARKUS-A сам предложит перенести задачи и заметки из старого Peskov Planner, если вы пользовались им в этом же браузере.

## Шаг 2. Подключить AI (бесплатно)

1. Откройте **https://aistudio.google.com/apikey** и войдите через Google.
2. **Create API key** → скопируйте ключ (начинается с `AIza…`).
3. В MARKUS-A: **Настройки → AI-помощник** → вставьте ключ → **Проверить AI**.

> Важно для конфиденциальных встреч: по условиям бесплатного тарифа Google может использовать отправленные данные для улучшения своих моделей. На платном тарифе Gemini (оплата по факту, центы за встречу) такого нет. Если записываете встречи с клиентами, решите, приемлемо ли это для вас.

## Шаг 3. Облако Supabase (синхронизация между устройствами)

1. **https://supabase.com** → **Start your project** → войдите через GitHub.
2. **New project**: имя `markus-a`, придумайте пароль базы (сохраните его), регион **Central EU (Frankfurt)** → **Create**. Подождите 1–2 минуты.
3. Слева **SQL Editor** → **New query** → откройте из архива файл `supabase/schema.sql`, скопируйте весь текст, вставьте → **Run**. Должно появиться «Success».
4. Слева **Authentication → Sign In / Providers → Email** → выключите **Confirm email** → **Save**. Тогда не нужно подтверждать почту при регистрации.
5. **Authentication → URL Configuration** → в **Site URL** впишите `https://arturmarkus2408-boop.github.io/markus-a/` → **Save**.
6. **Project Settings → API Keys**: скопируйте **Project URL** (вида `https://abcdxyz.supabase.co`) и **Publishable key** (`sb_publishable_…`; если его нет — ключ `anon public`).
7. На GitHub откройте файл `config.js` → карандаш ✏️ (Edit) → впишите:
   ```js
   SUPABASE_URL: 'https://abcdxyz.supabase.co',
   SUPABASE_KEY: 'sb_publishable_...',
   ```
   → **Commit changes**.

Этот ключ публичный, это нормально. Ваши данные защищены правилами доступа в базе: каждый видит только свои записи.

## Шаг 4. Аккаунт

1. На телефоне: MARKUS-A → **Настройки → Облако** → email и пароль → **Регистрация**.
2. На компьютере: те же email и пароль → **Войти**.

Ключ AI подтянется на второе устройство сам.

## Шаг 5. Создать Telegram-бота

1. В Telegram откройте **@BotFather** → `/newbot`.
2. Имя: `MARKUS-A`. Username: любое свободное, заканчивающееся на `bot`, например `markus_a_timur_bot`.
3. BotFather пришлёт **токен** (вида `123456:ABC-...`) — сохраните его.
4. На GitHub в `config.js` впишите `TELEGRAM_BOT: 'markus_a_timur_bot'` (без @) → **Commit**.

## Шаг 6. Серверные функции (бот и напоминания)

**6.1. Секреты.** Supabase → **Edge Functions → Secrets** → добавьте по одному:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | придумайте: латиница и цифры, например `mk7Hq29xLp` |
| `CRON_SECRET` | придумайте другой, например `cr0n55Tqz` |
| `GEMINI_API_KEY` | ключ из шага 2 |
| `APP_URL` | `https://arturmarkus2408-boop.github.io/markus-a` |

**6.2. Функция бота.** Edge Functions → **Deploy a new function** → **Via Editor** → имя **`telegram-bot`** (точно так) → удалите пример кода → вставьте содержимое файла `supabase/functions/telegram-bot/index.ts` → **Deploy**.
Затем откройте функцию → **Details / Settings** → выключите **Verify JWT** (Enforce JWT verification) → **Save**.

**6.3. Функция напоминаний.** То же самое с именем **`reminders`** и файлом `supabase/functions/reminders/index.ts`. **Verify JWT** тоже выключить.

## Шаг 7. Связать Telegram с функцией

Откройте в браузере ссылку, подставив свои значения (одной строкой):

```
https://api.telegram.org/botВАШ_ТОКЕН/setWebhook?url=https://ВАШ_ПРОЕКТ.supabase.co/functions/v1/telegram-bot&secret_token=ВАШ_TELEGRAM_WEBHOOK_SECRET
```

Ответ должен содержать `"Webhook was set"`.

## Шаг 8. Запустить напоминания по расписанию

Откройте `supabase/cron.sql` и замените `ВАШ_ПРОЕКТ` и `ВАШ_CRON_SECRET`. Затем SQL Editor → вставить → **Run**.

После этого сервер каждую минуту проверяет напоминания и просрочки и пишет вам в Telegram, даже когда приложение закрыто.

## Шаг 9. Подключить Telegram в приложении

MARKUS-A → **Настройки → Telegram → Подключить Telegram** → откроется бот → **Start** → вернитесь в приложение → **Проверить**. Для проверки связи есть кнопка **Тест**.

## Шаг 10. Установить на Android

1. Откройте адрес приложения в **Chrome**.
2. Меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
3. При первом запуске разрешите **уведомления** и **микрофон**.

Долгое нажатие на иконку даёт быстрые действия: «Голос», «Новая задача», «Запись встречи».

## Как пользоваться

**Голос** — большая кнопка 🎙 на главном экране:
- «22 сентября в 10 утра до 11 подготовить договор с компанией Сфера»
- «Завтра в 14 часов встреча с Алишером на час»
- «Напомни через два часа позвонить бухгалтеру»
- «Что у меня сегодня после обеда?»
- «Найди свободное окно на полтора часа до пятницы»
- «Запиши: проверить договор до пятницы»

Если время не названо, MARKUS-A спросит его сам, а если оно занято — предложит свободные окна.

**Telegram:** пишите или отправляйте голосовые боту теми же фразами. Команды: `/today`, `/tomorrow`, `/week`. В напоминаниях есть кнопки «✓ Выполнено», «💤 +10 мин», «📅 На завтра».

**Встречи:** создайте встречу (можно с автозаписью) → в начале нажмите «Начать запись». После окончания MARKUS-A спросит, сохранить ли запись, сделает стенограмму и итоги: кратко, решения, обязательства, сроки, риски, следующие шаги. Задачи из разговора он создаст только после вашего подтверждения (это переключается в настройках).

## Честно об ограничениях

- **Автозапись.** Встреча записывается сама, только если MARKUS-A открыт на экране в момент её начала. Иначе приходит уведомление или сообщение в Telegram с кнопкой «Начать запись» — одно нажатие. Это ограничение Android и браузеров: сайт не может сам включить микрофон в фоне. Полная фоновая автозапись требует нативного Android-приложения, это следующий этап.
- **Напоминания при закрытом приложении** надёжно приходят через Telegram. Уведомления самого приложения работают, пока оно открыто или недавно свёрнуто.
- **Длина записи для AI** — до ~1 ч 40 мин за один раз (лимит бесплатного Gemini). Сама запись может быть любой длины.
- **Лимиты бесплатного AI**: несколько запросов в минуту. При частых командах подряд попросит подождать минуту.
- **«Поделиться»** работает в режимах просмотра и комментирования, со сроком действия, кодом и отзывом доступа. Совместного редактирования пока нет.
- **Supabase Free**: 500 МБ базы и 1 ГБ файлов. Если проектом долго не пользоваться, Supabase может его «усыпить» — тогда зайдите на supabase.com и нажмите **Restore**.
- Старые документы `.doc` AI не читает: сохраняйте как `.docx` или PDF.
