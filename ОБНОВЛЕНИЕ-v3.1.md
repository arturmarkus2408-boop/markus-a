# MARKUS-A 3.1 — что нового

* Поддержка Android-приложения MARKUS-A (запись встреч на заблокированном телефоне без нажатий).
  Установка — в файле «ИНСТРУКЦИЯ-УСТАНОВКА.md» из архива markus-a-android.zip.
* Если у одной встречи появляется вторая запись, первая не пропадает — она сохраняется в «Материалах» встречи.
* В браузере всё работает как в версии 3.0.

Как обновить сайт: загрузите в репозиторий markus-a все файлы из этого архива, кроме папки supabase
(Add file → Upload files → Commit changes). Сервер Supabase обновлять не нужно.
